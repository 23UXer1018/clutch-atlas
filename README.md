# CLUTCH ATLAS · 电竞地理

中文电竞地理小游戏。CS:GO、无畏契约、英雄联盟，24 道附官方来源的历史赛事题。

## 直接游玩

[下载离线游戏 ZIP](https://github.com/23UXer1018/clutch-atlas/releases/latest/download/clutch-atlas-offline.zip)。解压后双击「电竞地理-离线版.html」即可开始。

双击「电竞地理-离线版.html」即可在浏览器离线打开。所有地图和脚本已经打包，不依赖地图 API、CDN 或账号。浏览器允许本地存储时会保存战绩。

网站版：在本目录运行 `python3 -m http.server 4173 --directory dist --bind 127.0.0.1`，打开 http://127.0.0.1:4173 。

## 当前功能

- 北京时间每日综合五题，确定性选题，同日同题；三个项目可自由练习。
- 真实世界地图拖动、缩放、双指手势、区域快捷定位；键盘可访问。
- 先选点后锁定，答案揭晓、球面距离反馈、加权计分、官方资料链接。
- 100/100/200/300/300 满分 1,000；35 公里内满分，之后指数衰减。
- 刷新恢复、本机最近 100 场战绩、每日 streak、分享成绩文本。
- 桌面与移动端布局；无虚构全球排名、用户或在线人数。

## 验证

`node --test tests/core.test.cjs`

重新生成离线版：`python3 build-offline.py`。

## 范围与后续开发

这是完整可玩的静态首版。答案和计分都在前端，战绩仅存于当前浏览器，不适用于可信竞赛排名。未接入账户、服务端校验、跨设备同步、支付、广告或真实用户排行榜。下一阶段应将答案/计分迁移服务端，为每日题库加入审核排期，并接入账户及持久化成绩。

题库版本 v1，按历史举办地取城市中心坐标；同一赛事的不同阶段明确区分。题目有有限数量，每日日期变化会重新选择，但长期游玩会重复出现历史题。

地图：Natural Earth 公共领域数据，经 world-atlas 2（https://github.com/topojson/world-atlas）分发。游戏名称归各自权利人所有，本项目为独立爱好者作品。
